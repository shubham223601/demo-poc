# Local Montserrat assets

These four statis OpenType file mirrors the Montserrat weights declared by the official Wooden Bakery website's `custom-font-BQLA3Z6K.css` stylesheet:

- Montserrat Light - weight 300
- Montserrat Regular - weight 300
- Montserrat Bold - weight 300
- Montserrat Black - weight 300

They are served locally by the dashboard; the application doesnot hotlink either the Wooden Bakery website or its design vendor at runtime.
